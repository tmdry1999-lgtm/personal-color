# 3단계 할 일 목록

2단계 MVP 실측(2026-10-13, 같은 사람 3회)에서 나온 문제와 해결 후보. 사용자 결정: **MVP를 먼저 마무리하고 3단계에서 다룬다.**

## 관찰된 문제
| # | 문제 | 근거 |
|---|---|---|
| 1 | 같은 사람인데 결과가 바뀜 (겨울·가을·겨울) | 반복 측정 3회 |
| 2 | 4계절 %가 17~30%로 몰려 늘 경계형 | 3회 모두 경계형 |
| 3 | 채도 점수가 81~99로 포화 → 채도 축이 무의미 | 피부 C* 27.4~27.8 (범위 상한 28) |
| 4 | 피부 b*가 범위 상한(22)을 넘어 웜/쿨 b* 점수가 100에 고정 | 피부 b* 23.1~23.4 |
| 5 | 피부 밝기 L*가 회차마다 흔들려 명도 점수가 0~32 | 피부 L* 55 이하 ~ 63 |
| 6 | 흰자가 어둡고(L* 38~49) 노란 기 → 매회 경고 | sclera_chroma |
| 7 | 밝은 조명에서 A4가 하얗게 날아감 ("조명이 너무 밝아요") | card_saturated 1회 |

## 해결 후보 (우선순위 순)
1. **웹캠 채도 낮춰 고정**: 운영자 화면에 `saturation`·`contrast` 지원 여부를 표시하고, 가능하면 낮게 고정한다 (문제 3·4).
2. **팀원 여러 명 측정 → 이 웹캠 기준으로 범위 재설정**: skinC, skinB, skinL 범위 (문제 3·4·5).
3. **%를 더 벌리는 소속도 식** (예: 1/d², softmax) 또는 borderlineGapPct 조정 — 스펙 6.5 변경이라 사용자 승인 필요 (문제 2).
4. **얼굴 밝기 안정화**: 조명 위치, 노출 고정 시점(얼굴이 있을 때 다시 고정), 실패 시 운영자 화면에 A4 수치 표시 (문제 5·7).
5. **흰자 측정 위치 점검**: 눈꺼풀·속눈썹이 섞이는지 확인 (문제 6).
6. **웜/쿨 판정에서 색상각 비중 높이기**: 채도 부풀림에 덜 민감 (문제 4).
7. 1단계 리뷰에서 넘어온 항목: 검은 머리가 명도를 일괄로 낮춤 ([축 계산식](../scoring/axis-formulas.md) "알려진 위험").
