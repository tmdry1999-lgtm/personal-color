# 3단계 할 일 목록

2단계 MVP 실측(2026-10-13, 같은 사람 3회)에서 나온 문제와 해결 후보. 사용자 결정: **MVP를 먼저 마무리하고 3단계에서 다룬다.**

## 관찰된 문제
| # | 문제 | 근거 |
|---|---|---|
| 1 | 같은 사람인데 결과가 바뀜 (겨울·가을·겨울) | 반복 측정 3회 |
| 2 | 4계절 %가 17~30%로 몰려 늘 경계형 | 3회 모두 경계형 |
| 3 | 채도 점수가 81~99로 포화 → 채도 축이 무의미 | 피부 C* 27.4~27.8 (범위 상한 28) |
| 4 | 피부 b*가 범위 상한(22)을 넘어 웜/쿨 b* 점수가 100에 고정 | 피부 b* 23.1~23.4 |
| 5 | 피부 밝기 L*가 회차마다 흔들려 명도 점수가 0~32 | 피부 L* 55 이하 ~ 63 |
| 6 | 흰자가 어둡고(L* 38~49) 노란 기 → 매회 경고 | sclera_chroma |
| 7 | 밝은 조명에서 A4가 하얗게 날아감 ("조명이 너무 밝아요") | card_saturated 1회 |

## 해결 후보 (우선순위 순)
1. **웹캠 채도 낮춰 고정**: 운영자 화면에 `saturation`·`contrast` 지원 여부를 표시하고, 가능하면 낮게 고정한다 (문제 3·4).
2. **팀원 여러 명 측정 → 이 웹캠 기준으로 범위 재설정**: skinC, skinB, skinL 범위 (문제 3·4·5).
3. **%를 더 벌리는 소속도 식** (예: 1/d², softmax) 또는 borderlineGapPct 조정 — 스펙 6.5 변경이라 사용자 승인 필요 (문제 2).
4. **얼굴 밝기 안정화**: 조명 위치, 노출 고정 시점(얼굴이 있을 때 다시 고정), 실패 시 운영자 화면에 A4 수치 표시 (문제 5·7).
5. **흰자 측정 위치 점검**: 눈꺼풀·속눈썹이 섞이는지 확인 (문제 6).
6. **웜/쿨 판정에서 색상각 비중 높이기**: 채도 부풀림에 덜 민감 (문제 4).
7. 1단계 리뷰에서 넘어온 항목: 검은 머리가 명도를 일괄로 낮춤 ([축 계산식](../scoring/axis-formulas.md) "알려진 위험").

## 코드 정리 (2단계 최종 리뷰에서 미룬 것)
- 오류 문구 타이머끼리 서로 가림 (3초짜리 문구가 고정 문구를 숨김, 카메라 성공 시 모델 실패 문구도 지워짐)
- 운영자가 웹캠을 빠르게 바꾸면 이전 카메라가 꺼지지 않을 수 있음
- 웹캠 이름을 innerHTML로 넣음 → `new Option()` 사용
- A4 드래그 중 포인터가 영역 밖에서 떼어지면 드래그가 멈춤 → `setPointerCapture`
- 머리카락 분리 모델 주소가 `latest` → 버전 고정
- 오버레이 캔버스 크기를 매 프레임 다시 설정 (성능)

## 데이터 수집 메모 (2026-10-13)
- 사용자 결정: 조명 구매 없이 **지금 사무실 환경에서 계속** 측정한다. 18% 회색 카드는 사용자가 구매한다.
- A4로 모은 데이터는 회색 카드 도착 후 **환산 세션 1회**가 필요하다: 같은 사람·같은 자리에서 A4와 회색 카드를 함께 화면에 두고 측정 → A4의 실제 반사율(앱 가정 0.8과의 차이)을 구해 이전 데이터를 환산한다. 측정 기록에는 `cardType`이 남는다.
- 측정 중에는 조명·A4 위치·웹캠 설정을 바꾸지 않는다.

## 화장·안경 대응 (2026-10-13, 사용자 결정 변경: P4~P6 결과를 보고 **먼저 만든다** — 1·3번과 측정 기록 보존 구현됨, 판정 반영은 데이터 후)
근거: P2(화장, 전문가 진단 가을 웜)가 앱에서 겨울 브라이트로 나옴. P3(안경)의 눈동자·흰자가 초록빛으로 측정됨.
1. **목 피부 측정**: 멀티클래스 분리의 몸 피부(클래스 2)로 목을 측정. "베이스 화장했어요" 체크 시 웜/쿨·채도는 목, 밝기는 얼굴로 판정 (목은 턱 그림자로 어두움).
2. 화장 체크 시 눈동자·(염색 안 한) 머리카락 가중치 올리기.
3. 시작 화면에 "안경은 잠시 벗어 주세요" 안내 + 눈동자 색상각이 비정상(초록빛)이면 그 회차 눈동자 제외.
4. 데이터 수집 양식에 베이스 화장·안경·전문가 진단 여부를 함께 적는다. 범위 재설정 기준 데이터는 맨얼굴·안경 벗은 상태를 우선한다.

## 부스 설치 전 남은 수동 점검
- 안드로이드 폰으로 QR 결과 페이지 열기 (아이폰은 확인됨)
- 카운트다운 중 두 번째 사람이 들어오면 카운트다운 초기화 (2단계에서 건너뜀)
- 결과 화면 60초 무조작 → 대기 화면 복귀 (2단계에서 건너뜀)
- 반복성 5회 테스트를 3단계 수정 후 다시 실시 (2단계 3회 결과: 2/3, 기준 4/5 미달)
