**3단계-A 브랜치에 들어 있는 기능**
- 웹캠 채도·색온도·노출 시간을 숫자로 저장하고 켤 때마다 다시 적용 (슬라이더 + 숫자 입력, 초기화 버튼)
- 측정 기록 모드: 성공한 측정만, 참가자·성별·체크 항목·웹캠 설정·카드 종류·환경 메모 포함, 탭 닫을 때까지 보관, [모두 복사]
- 목 피부 측정 (얼굴 사진 속 목, 빛 받은 부분만, 턱 든 목 사진) — **기록만, 판정에 안 씀**
- 시작 화면: "베이스 화장했어요" 체크, "안경은 잠시 벗어 주세요"
- 베이스 화장 체크 시 턱 들기 인식(12°) 후 목 촬영, 10초 넘으면 건너뜀
- 눈동자 색상각 90° 초과(안경 반사) 자동 제외
- 운영자 창이 오른쪽에 붙고 미리보기를 가리지 않음

## 2. 오늘 내린 결정
1. 색 변환은 culori 4.0.2 (npm + 브라우저 import map), 반드시 `lab65`
2. 웹캠 설정은 숫자로 고정하고 측정 중 바꾸지 않는다
3. 18% 회색 카드를 사용자가 구매한다 → A4 데이터 환산 세션 1회 필요
4. **부스 조명을 마련한다.** 조명이 정해지기 전에는 기준 범위를 조정하지 않는다 (조명이 바뀌면 데이터가 달라지므로)

## 3. 다음 할 일 (순서대로)
1. **부스 조명 마련**: 정면 확산광(디퓨저 링라이트 또는 좌우 45° LED 패널 2개), **CRI 95 이상·R9 80 초과**, 5000~6500K, 밝기 조절 가능. 천장 조명·창문 빛은 가린다. 기준: [조명 조건](../measurement/lighting.md)
2. **18% 회색 카드 도착** → 조명 아래에서 A4와 회색 카드를 함께 두고 1회 측정(환산 세션). 이후 기준 카드를 회색 카드로 바꿀지 결정
3. **조명 아래에서 웹캠 설정 다시 잡기**: 기준 카드가 하얗게 날아가지 않는 노출 값을 찾아 고정
4. **재측정**: 전문가 진단자 4명(P2 가을 웜, P5 가을 웜/겨울 쿨, P6 봄 웜, P7 여름·가을 뮤트) + 맨얼굴 여러 명. 목표 8~10명, 1명당 3회. 안경 벗고, 측정 전에 참가자 번호부터 바꾸기, 붙인 뒤 [비우기]
5. **데이터로 결정**:
   - 목 값 중 무엇을(얼굴 사진 속 목 / 밝은 부분만 / 턱 든 목) 웜/쿨 판정에 쓸지
   - 조명이 좋으면 턱 들기 단계를 없앨지 (반사판 실험에서 턱 든 목 ≈ 얼굴 사진 속 목)
6. **기준 범위 재설정**: 피부 채도·b*·밝기·색상각, 목 전용 범위. 필요하면 %를 더 벌리는 식(스펙 6.5 변경 → 승인 필요)
7. **반복성 5회 재테스트** (기준 4/5)
8. `phase3a-camera` 브랜치 리뷰 → master 병합 → 배포 — **2026-10-15 조명보다 먼저 진행** (`docs/plans/2026-10-15-phase3a-release.md`: 운영자 모드, 웹캠별 설정)
