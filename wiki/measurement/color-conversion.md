# 색 변환 (sRGB → Lab)

앱에서는 culori 라이브러리로 변환한다. **반드시 `lab65` 모드(D65)를 쓴다.** culori 기본 `lab`은 D50이라 값이 다르다(예: `#DCB496` a* 10.19 → 11.81). 이 문서는 **검증 기준**이다. 테스트는 아래 정답값과 비교한다.

## 1. sRGB → 선형 RGB
각 채널을 0~1로 나눈 값 v에 대해:
```
v ≤ 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ^ 2.4
```
A4 보정의 평균·배율 계산은 이 선형값으로 한다.

## 2. 선형 RGB → XYZ (D65)
```
X = 0.4124564 R + 0.3575761 G + 0.1804375 B
Y = 0.2126729 R + 0.7151522 G + 0.0721750 B
Z = 0.0193339 R + 0.1191920 G + 0.9503041 B
```

## 3. XYZ → Lab
기준 백색 Xn = 0.95047, Yn = 1, Zn = 1.08883
```
f(t) = t > 216/24389 ? ∛t : (24389/27 · t + 16) / 116
L* = 116 · f(Y/Yn) − 16
a* = 500 · (f(X/Xn) − f(Y/Yn))
b* = 200 · (f(Y/Yn) − f(Z/Zn))
```

## 4. 파생값
```
C*  = √(a*² + b*²)
h°  = atan2(b*, a*) × 180/π   (음수면 +360)
ITA = arctan((L* − 50) / b*) × 180/π
```

## 검증용 정답값

| 입력 | L* | a* | b* | h° |
|---|---|---|---|---|
| `#FFFFFF` | 100 | 0 | 0 | — |
| `#000000` | 0 | 0 | 0 | — |
| `#FF0000` | ≈ 53.24 | ≈ 80.09 | ≈ 67.20 | ≈ 40.0 |
| `#0000FF` | — | — | — | ≈ 306.3 |

`tools/validate-data.js`의 `hexToHueDeg`가 같은 공식을 쓰고, 빨강·파랑 값으로 테스트된다.

## ITA 피부 밝기 구간 (참고)
매우 밝음 > 55°, 밝음 41~55°, 중간 28~41°, 황갈 10~28°, 갈색 −30~10°, 어두움 < −30°
(원문 미열람, 일반적으로 인용되는 구간)
