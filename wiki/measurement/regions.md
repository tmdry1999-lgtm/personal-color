# 측정 부위

## 왜 여러 부위인가
- 퍼스널컬러는 피부·머리카락·눈동자의 조합으로 정의된다.
- Lumina 연구: 눈과 머리카락 특징이 피부만보다 정보량이 크다.
- 국내 퍼지 진단 특허: 피부 > 머리카락 > 눈동자 순으로 가중치를 둔다.
- 대비 축은 머리카락·눈 없이 계산할 수 없다.

## 부위 표 (스펙 6.3)

| 부위 | 위치 찾기 | 쓰는 축 | 제외 조건 |
|---|---|---|---|
| 피부 (양 볼, 이마, 턱) | MediaPipe 얼굴 점 | 웜/쿨, 명도, 채도 (주 근거) | 각 영역 L* 상하위 10% 픽셀 제거 |
| 눈동자 | 홍채 점 10개 | 대비, 웜/쿨 보조 | 눈 감음, 안경 반사 감지 |
| 머리카락 | MediaPipe 멀티클래스 분리 (클래스 1) | 대비, 명도 보조 | "염색" 체크 또는 채도가 설정값 초과 |
| 입술 | 입술 윤곽 점 | 웜/쿨 보조 | "립 제품" 체크 또는 채도가 설정값 초과 |
| 눈썹 | 눈썹 점 | 대비 보조 (낮은 가중치) | 없음 |

설정값(채도 기준 등)은 [임계값](../scoring/thresholds.md)에 있다.

## 이상치 제거
- 각 영역에서 L* 기준 상위 10%(반사광)와 하위 10%(그림자) 픽셀을 버린다.

## 촬영 조건
| 조건 | 기준 |
|---|---|
| 얼굴 수 | 정확히 1개 |
| 얼굴 크기 | 얼굴 폭 ≥ 화면 폭의 25% |
| 고개 회전 | ≤ 15° |
| 유지 시간 | 조건이 3초 유지되면 촬영 |
| 촬영 | 1초 동안 10장, 부위별 측정값은 10장의 **중앙값** |

## 흰자 교차 확인
- 눈 흰자는 거의 무채색이다. A4 보정 후 흰자의 C*가 12를 넘으면 보정이 의심스럽다는 뜻이다.
- MVP에서는 운영자 화면에 경고만 남기고 결과는 막지 않는다.

## 자기 신고 체크
- "염색했어요" → 머리카락을 모든 축 계산에서 제외 (대비는 눈동자·눈썹으로 계산)
- "립 제품을 발랐어요" → 입술 제외
- 제외된 부위의 가중치는 같은 축의 남은 부위에 비례 배분한다([축 계산식](../scoring/axis-formulas.md)).
- 체크하지 않아도 채도 기준으로 자동 감지해 제외한다.
