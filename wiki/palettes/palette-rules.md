# 팔레트 규칙

## 베스트 색 만드는 규칙
```
베스트 = 톤의 PCCS 톤(명도·채도) × 계절의 색상 방향(웜 = 노란 기, 쿨 = 푸른 기)
```
- PCCS 대응: [PCCS 톤 체계](../theory/pccs-tones.md)의 "12톤 ↔ PCCS 톤" 표
- 예: 봄 라이트 = p·lt 톤 × 노란 기 → 피치, 라이트 코랄, 버터 옐로
- 예: 여름 라이트 = p·lt 톤 × 푸른 기 → 파우더 핑크, 라벤더, 스카이 블루

## 워스트 색 만드는 규칙
반대 온도 + 반대 명도·채도.
- 봄 라이트(웜·밝음)의 워스트 → 차갑고 어둡거나 강한 색 (블랙, 버건디, 쿨 퓨셔)
- 겨울 딥(쿨·어두움)의 워스트 → 따뜻하고 밝은 색 (파스텔 옐로, 피치, 코랄)

## 무채색 규칙
- **블랙**: 겨울 브라이트·트루·딥에서만 베스트. 대비가 큰 사람에게 어울린다.
- **퓨어 화이트**: 겨울 브라이트·트루에서만 베스트. 겨울 딥은 어두운 색 위주라 넣지 않았다.
- 블랙이 워스트인 톤: 봄 라이트, 봄 트루, 여름 라이트, 여름 소프트, 가을 소프트
- 퓨어 화이트가 워스트인 톤: 가을 소프트
- 여름은 블랙 대신 소프트 네이비, 퓨어 화이트 대신 소프트·쿨 화이트.

## 자동 검사 (`tests/palettes-data.test.js`)
무채색을 뺀 베스트 색 중 CIELAB 색상각 30~100°(주황~노랑 쪽) 비율:
- 웜 톤(봄·가을): **절반 이상**
- 쿨 톤(여름·겨울): **1/3 이하**

1단계 작성 시점의 결과: 웜 톤 0.67~0.83, 쿨 톤 0~0.25. 모두 통과.

## 적용 우선순위 (얼굴과 가까운 순)
립·블러셔 → 헤어 → 상의 → 금속 액세서리 (톤모아)

결과 화면은 이 순서로 중요도를 둔다. 표시 규칙은 [계절 추가 항목](season-extras.md) 참고.

## 한계
- 색 이름과 hex는 PCCS 규칙에 맞춰 직접 고른 **초안**이다. 공식 PCCS 색표 값이 아니다.
- 4단계 드레이핑 화면에서 실제 얼굴 옆에 대보고 조정한다.
