# 5단계(앞당김): 발표용 디자인 MVP 계획

> 2026-10-19 오늘 20:00 발표용. 시간 관계상 스펙과 계획을 이 문서 하나로 합친다 (사용자 승인 2026-10-19 14시대).

**Goal:** 부스 화면 6개(대기·시작·촬영·턱 들기·분석 중·결과)와 QR 결과 페이지에 일관된 시각 디자인을 입힌다. 판정 로직·화면 흐름은 바꾸지 않는다.

**Spec 근거:** `docs/specs/2026-10-12-personal-color-booth-design.md` 7장 (화면 구성), 5단계 "디자인"을 앞당기고 4단계 중 "근거 그래프"만 같이 한다.

## 사용자 결정 (2026-10-19)
1. 범위: 부스 앱 화면 + QR 결과 페이지. 별도 소개 홈페이지는 만들지 않음
2. 결과 화면: 이미 있는 데이터만 시각화 — 4계절 % 막대, 4축 양쪽 막대, 큰 컬러 칩, 계절 키워드. 드레이핑은 하지 않음
3. 색: **PANTONE 11-4201 Cloud Dancer**(바탕) + **딥퍼플**(글자·주요 버튼)
4. 레퍼런스: toss.im의 부드러움(여백, 큰 글자, 차분한 움직임). 단 "흔한 AI 생성 UI" 느낌은 피한다: 과한 둥근 모서리, 그라데이션 카드, 이모지 아이콘, 유리 효과를 쓰지 않는다

## 디자인 방향: "색 견본집"
- 바탕 Cloud Dancer `#F0EEE9`, 글자 딥퍼플 `#2B1A3F`, 보조 글자 `#6B6177`, 선 `#D9D3CC`, 강조 퍼플 `#4B2A7B`
- 모서리 2~4px, 그림자 없이 1px 선으로 구분. 페인트 견본 칩처럼 색 면 + 아래 흰 이름표(이름, HEX)
- 글꼴: 제목 Noto Serif KR(Google Fonts), 본문 Pretendard(jsDelivr), 라벨·숫자 IBM Plex Mono. 모두 시스템 글꼴 대체 지정
- 작은 영문 대문자 라벨과 번호(01, 02…)로 잡지 같은 정보 구조
- 화면 전환: 0.4초 페이드 + 8px 상승. `prefers-reduced-motion`이면 없음

## 바꾸는 파일
- `app/style.css` — 새로 작성 (운영자 창 스타일은 유지·정리)
- `app/index.html` — 화면 마크업 정리. **기존 id는 모두 유지** (app.js·operator.js가 쓰므로)
- `app/result.html` — 같은 스타일, 세로 배치
- `app/src/result-view.js` — 결과 HTML 생성 (막대·칩·키워드)
- `tests/result-view.test.js` — 새 구조 기준으로 보강

## 지켜야 할 것
- 문구 그대로: "사진은 저장되지 않으며, 진단 후 즉시 삭제됩니다", "사진 등의 개인정보는 저장되지 않습니다", "참고용 결과예요"
- 판정 기준값·흐름·QR 형식 변경 없음. 테스트 149개는 그대로 통과
- 4축 값은 0~100, 높을수록 웜 / 밝음 / 선명 / 대비 큼 (`wiki/scoring/axis-formulas.md`)
- 결과 HTML에 들어가는 문자열은 팔레트 JSON에서 오지만 innerHTML로 넣으므로 이름은 이스케이프한다
