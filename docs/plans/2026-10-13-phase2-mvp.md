# 2단계: MVP 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 웹캠 앞에 서면 대기 → 시작 → 촬영 → A4 보정 → 4계절·12톤 판정 → 텍스트 결과 → QR까지 끊김 없이 동작하는 부스 앱과, QR로 여는 결과 페이지를 만든다. 디자인은 넣지 않는다.

**Architecture:** 계산 부분(`color → calibrate → measure → regions → axes → classify → result-code → pipeline`)은 카메라·화면 없이 숫자만 다루는 순수 ES 모듈이라 Node에서 테스트한다. 브라우저 부분(`camera`, `face`, `operator`, `app`)은 이 순수 모듈을 불러 화면을 그린다. 같은 `app/` 폴더를 로컬 서버와 GitHub Pages가 그대로 제공한다.

**Tech Stack:** HTML + ES 모듈(빌드 없음), MediaPipe Tasks Vision 1.1.0(CDN), qrcode-generator 2.0.4(CDN), Node 24 `node:test`

**Spec:** `docs/specs/2026-10-12-personal-color-booth-design.md`

## 스펙과 다른 점 (사용자 승인 필요)

1. **culori 대신 자체 색 변환(`app/src/color.js`)을 쓴다.** 순수 모듈이 CDN을 불러오면 Node 테스트가 불가능해진다. 변환 공식은 위키 `measurement/color-conversion.md`에 있고, 1단계에서 이미 검증값으로 테스트했다. CIEDE2000은 MVP에서 쓰지 않는다.
2. **라이브러리 버전 고정:** MediaPipe Tasks Vision `1.1.0`, qrcode-generator `2.0.4` (npm 레지스트리에서 파일·API 이름 확인함. CDN 접속은 이 개발 환경에서 막혀 있어 브라우저에서 확인).
3. **GitHub Pages는 저장소 루트를 제공한다.** 부스 주소는 `https://<계정>.github.io/personal-color/app/`, QR 주소는 `.../app/result.html?...`.

## Global Constraints

- 사진·프레임 픽셀은 메모리에서만 쓰고, 분석이 끝나면 참조를 버린다. 디스크·서버·`localStorage`·로그에 저장하지 않는다. `localStorage`에는 운영자 설정(웹캠 id, A4 영역, 카드 종류)만 둔다.
- QR URL에는 결과 숫자만 담는다: `v, g, s, t, p, x, b` (스펙 7.4).
- 외부 npm 패키지를 설치하지 않는다. 브라우저 라이브러리는 CDN `https://cdn.jsdelivr.net/npm/...`에서 정확한 버전으로 불러온다.
- 화면 문구(한국어)는 스펙 그대로: 시작 화면 "사진은 저장되지 않으며, 진단 후 즉시 삭제됩니다", 결과 화면·QR 페이지 "사진 등의 개인정보는 저장되지 않습니다", "참고용 결과예요".
- 숫자 기준값은 코드에 쓰지 않고 `app/data/seasons.json`에서 읽는다.
- 4계절 id 순서 `spring, summer, autumn, winter`, 4축 순서 `warmth, value, chroma, contrast`.
- 대상 브라우저: Windows Chrome (부스 PC). 웹캠은 `localhost` 또는 https에서만 켜진다.
- 위키를 바꾸면 `wiki/log.md`에 한 줄 기록하고, `seasons.json`과 위키 표를 같이 고친다.

```js
// 공식과 검증값: wiki/measurement/color-conversion.md
const WHITE = [0.95047, 1, 1.08883];

export function srgbToLinear(v) {
  const c = v / 255;
  return c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4;
}

export function linearToSrgb(c) {
  const v = c <= 0.0031308 ? 12.92 * c : 1.055 * c ** (1 / 2.4) - 0.055;
  return Math.round(Math.min(1, Math.max(0, v)) * 255);
}

export function linearToLab([r, g, b]) {
  const x = (0.4124564 * r + 0.3575761 * g + 0.1804375 * b) / WHITE[0];
  const y = (0.2126729 * r + 0.7151522 * g + 0.0721750 * b) / WHITE[1];
  const z = (0.0193339 * r + 0.1191920 * g + 0.9503041 * b) / WHITE[2];
  const f = (t) => (t > 216 / 24389 ? Math.cbrt(t) : (24389 / 27 * t + 16) / 116);
  return { L: 116 * f(y) - 16, a: 500 * (f(x) - f(y)), b: 200 * (f(y) - f(z)) };
}

export function withLch({ L, a, b }) {
  const C = Math.hypot(a, b);
  // 무채색은 색상각이 정의되지 않는다
  const h = C < 1 ? NaN : (Math.atan2(b, a) * 180 / Math.PI + 360) % 360;
  return { L, a, b, C, h };
}

export function rgbToLch(rgb) {
  return withLch(linearToLab(rgb.map(srgbToLinear)));
}

export function hexToRgb(hex) {
  return [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16));
}
```

```js
// 원리: wiki/measurement/reference-card.md
import { srgbToLinear } from './color.js';

const luminance = ([r, g, b]) => 0.2126 * r + 0.7152 * g + 0.0722 * b;

export function cardStats(pixels) {
  if (!pixels || pixels.length === 0) return null;
  const lin = pixels.map((p) => p.map(srgbToLinear));
  const mean = [0, 1, 2].map((i) => lin.reduce((s, p) => s + p[i], 0) / lin.length);
  const saturatedRatio = lin.filter((p) => Math.max(...p) >= 0.98).length / lin.length;
  const lum = lin.map(luminance);
  const lumMean = lum.reduce((s, v) => s + v, 0) / lum.length;
  const sd = Math.sqrt(lum.reduce((s, v) => s + (v - lumMean) ** 2, 0) / lum.length);
  return { mean, saturatedRatio, relStd: lumMean > 0 ? sd / lumMean : Infinity };
}

export function checkCard(stats, t) {
  if (!stats) return 'card_missing';
  if (stats.saturatedRatio > t.cardMaxSaturatedRatio) return 'card_saturated';
  if (Math.min(...stats.mean) <= 0.01) return 'card_dark';
  if (stats.relStd > t.cardMaxRelStd) return 'card_occluded';
  return null;
}

export function computeGains(mean, target) {
  return target.map((t, i) => t / mean[i]);
}
```

```js
// 절차: wiki/measurement/regions.md
import { srgbToLinear, linearToLab, withLch, rgbToLch } from './color.js';

export function measureRegion(pixels, gains, trimPct, minPixels) {
  if (!pixels || pixels.length < minPixels) return null;
  const labs = pixels.map((p) => linearToLab(p.map((v, i) => Math.min(1, srgbToLinear(v) * gains[i]))));
  labs.sort((x, y) => x.L - y.L);
  const k = Math.floor((labs.length * trimPct) / 100);
  const kept = labs.slice(k, labs.length - k);
  const avg = (key) => kept.reduce((s, c) => s + c[key], 0) / kept.length;
  return withLch({ L: avg('L'), a: avg('a'), b: avg('b') });
}

export function median(values) {
  const s = [...values].sort((a, b) => a - b);
  const mid = Math.floor(s.length / 2);
  return s.length % 2 ? s[mid] : (s[mid - 1] + s[mid]) / 2;
}

export function combineFrames(measures) {
  const ok = measures.filter(Boolean);
  if (ok.length === 0 || ok.length * 2 < measures.length) return null;
  return withLch({
    L: median(ok.map((m) => m.L)),
    a: median(ok.map((m) => m.a)),
    b: median(ok.map((m) => m.b)),
  });
}

export function hasGlare(pixels, minL, maxRatio) {
  if (!pixels || pixels.length === 0) return false;
  return pixels.filter((p) => rgbToLch(p).L > minL).length / pixels.length > maxRatio;
}
```

```js
      if (d <= r && d >= rInner) out.push(pixelAt(img, x, y));
    }
  }
  return out;
}

export function samplePolygon(img, poly, hole = null) {
  const out = [];
  const xs = poly.map((p) => p.x);
  const ys = poly.map((p) => p.y);
  const y0 = Math.max(0, Math.floor(Math.min(...ys)));
  const y1 = Math.min(img.height - 1, Math.ceil(Math.max(...ys)));
  const x0 = Math.max(0, Math.floor(Math.min(...xs)));
  const x1 = Math.min(img.width - 1, Math.ceil(Math.max(...xs)));
  for (let y = y0; y <= y1; y++) {
    for (let x = x0; x <= x1; x++) {
      if (pointInPolygon(x, y, poly) && !(hole && pointInPolygon(x, y, hole))) out.push(pixelAt(img, x, y));
    }
  }
  return out;
}

export function sampleRect(img, rect, step = 2) {
  if (!rect) return [];
  const out = [];
  const x0 = Math.max(0, Math.floor(rect.x * img.width));
  const y0 = Math.max(0, Math.floor(rect.y * img.height));
  const x1 = Math.min(img.width, Math.ceil((rect.x + rect.w) * img.width));
  const y1 = Math.min(img.height, Math.ceil((rect.y + rect.h) * img.height));
  for (let y = y0; y < y1; y += step) for (let x = x0; x < x1; x += step) out.push(pixelAt(img, x, y));
  return out;
}

export function sampleMask(img, mask, category, step = 4) {
  if (!mask) return [];
  const out = [];
  for (let y = 0; y < img.height; y += step) {
    const my = Math.floor((y * mask.height) / img.height);
    for (let x = 0; x < img.width; x += step) {
      const mx = Math.floor((x * mask.width) / img.width);
      if (mask.data[my * mask.width + mx] === category) out.push(pixelAt(img, x, y));
    }
  }
  return out;
}

export function eyeOpenRatio(img, lm, eye) {
  const P = (i) => toPx(img, lm[i]);
  return dist(P(eye.lids[0]), P(eye.lids[1])) / dist(P(eye.corners[0]), P(eye.corners[1]));
}

export function extractRegions(img, lm, hairMask, t) {
  const P = (i) => toPx(img, lm[i]);
  const faceW = dist(P(LM.faceEdges[0]), P(LM.faceEdges[1]));
  const circleAt = (i, r) => sampleCircle(img, P(i).x, P(i).y, r);

  const skin = [
    ...LM.cheeks.flatMap((i) => circleAt(i, 0.06 * faceW)),
    ...circleAt(LM.forehead, 0.04 * faceW),
    ...circleAt(LM.chin, 0.04 * faceW),
  ];

  const iris = [];
  const sclera = [];
  for (const eye of LM.eyes) {
    if (eyeOpenRatio(img, lm, eye) < t.eyeOpenMinRatio) continue;
    const c = P(eye.iris);
    const r = dist(c, P(eye.irisEdge));
    iris.push(...sampleCircle(img, c.x, c.y, 0.85 * r, 0.35 * r)); // 동공 제외
    for (const k of eye.corners) {
      const q = P(k);
      sclera.push(...sampleCircle(img, c.x + 0.65 * (q.x - c.x), c.y + 0.65 * (q.y - c.y), 0.25 * r));
    }
  }

  const poly = (ids) => ids.map(P);
  return {
    skin,
    iris,
    sclera,
    lip: samplePolygon(img, poly(LM.lipsOuter), poly(LM.lipsInner)),
    brow: LM.brows.flatMap((b) => samplePolygon(img, poly(b))),
    hair: sampleMask(img, hairMask, HAIR_CATEGORY),
  };
}
```

```js
// 계산식: wiki/scoring/axis-formulas.md
import { AXES } from './constants.js';

export function featureScore(x, [min, max]) {
  return Math.min(1, Math.max(0, (x - min) / (max - min))) * 100;
}

const usable = (c) => (c && !Number.isNaN(c.h) ? c.h : null);
// 입술은 빨강 근처라 0°/360° 경계를 넘나든다. -180~180으로 펼친다.
const signedHue = (h) => (h === null ? null : h > 180 ? h - 360 : h);

export function buildFeatures(m, flags, t) {
  const excluded = [];
  let hair = m.hair ?? null;
  if (hair && flags.dyed) { excluded.push('hair:self_report'); hair = null; }
  else if (hair && hair.C > t.hairDyeMinChroma) { excluded.push('hair:auto'); hair = null; }
  let lip = m.lip ?? null;
  if (lip && flags.lipProduct) { excluded.push('lip:self_report'); lip = null; }
  else if (lip && lip.C > t.lipProductMinChroma) { excluded.push('lip:auto'); lip = null; }
  const s = m.skin;
  const iris = m.iris ?? null;
  const brow = m.brow ?? null;
  return {
    excluded,
    features: {
      skinHueDeg: usable(s),
      skinB: s.b,
      lipHueDeg: signedHue(usable(lip)),
      irisHueDeg: usable(iris),
      skinL: s.L,
      hairL: hair ? hair.L : null,
      skinC: s.C,
      deltaLHair: hair ? s.L - hair.L : null,
      deltaLIris: iris ? s.L - iris.L : null,
      deltaLBrow: brow ? s.L - brow.L : null,
    },
  };
}

export function computeAxes(features, config) {
  return AXES.map((axis) => {
    const mapping = config.axisMapping[axis];
    let sum = 0;
    let wsum = 0;
    for (const [key, w] of Object.entries(config.featureWeights[axis])) {
      const x = features[key];
      if (x === null || x === undefined || Number.isNaN(x)) continue;
      sum += w * featureScore(x, mapping[key]);
      wsum += w;
    }
    return wsum > 0 ? sum / wsum : 50;
  });
}
```

```js
// 판정: wiki/scoring/season-prototypes.md, wiki/scoring/tone-rules.md
import { SEASONS, AXES } from './constants.js';

export function classify(axes, config) {
  const w = config.axisWeights;
  const d = SEASONS.map((s) => Math.sqrt(
    config.seasons[s].prototype.reduce((acc, p, i) => acc + w[i] * (axes[i] - p) ** 2, 0),
  ));
  const zero = d.findIndex((v) => v === 0);
  let pct;
  if (zero >= 0) {
    pct = d.map((_, i) => (i === zero ? 100 : 0));
  } else {
    const inv = d.map((v) => 1 / v);
    const sum = inv.reduce((a, b) => a + b, 0);
    pct = inv.map((v) => (v / sum) * 100);
  }

  // 정렬이 안정적이라 % 동점이면 SEASONS 순서가 앞선다
  const ranked = SEASONS.map((s, i) => ({ s, p: pct[i] })).sort((a, b) => b.p - a.p);
  const season = ranked[0].s;
  const borderline = ranked[0].p - ranked[1].p < config.thresholds.borderlineGapPct ? ranked[1].s : null;

  const proto = config.seasons[season].prototype;
  const tones = Object.entries(config.toneRules)
    .filter(([, r]) => r.season === season)
    .map(([id, r], idx) => {
      const ai = AXES.indexOf(r.axis);
      return { id, idx, score: r.direction * (axes[ai] - proto[ai]), isTrue: id.endsWith('-true') };
    });
  // 점수 큰 순 → 동점이면 트루 → 그래도 같으면 toneRules 순서
  tones.sort((a, b) => b.score - a.score || Number(b.isTrue) - Number(a.isTrue) || a.idx - b.idx);

  return {
    season,
    tone: tones[0].id,
    borderline,
    pct: Object.fromEntries(SEASONS.map((s, i) => [s, pct[i]])),
  };
}
```

```js
import { SEASONS, TONES } from './constants.js';

export function encodeResult({ gender, season, tone, pct, axes, borderline }) {
  const q = new URLSearchParams({
    v: '1',
    g: gender,
    s: season,
    t: tone,
    p: SEASONS.map((s) => Math.round(pct[s])).join(','),
    x: axes.map((a) => Math.round(a)).join(','),
  });
  if (borderline) q.set('b', borderline);

}

function fourInts(str) {
  if (!str) return null;
  const parts = str.split(',');
  if (parts.length !== 4) return null;
  const n = parts.map((v) => (/^\d+$/.test(v) ? Number(v) : NaN));
  return n.every((v) => Number.isInteger(v) && v >= 0 && v <= 100) ? n : null;
}

export function decodeResult(search) {
  const q = new URLSearchParams(search);
  if (q.get('v') !== '1') return null;
  const gender = q.get('g');
  const season = q.get('s');
  const tone = q.get('t');
  const borderline = q.get('b');
  if (!['f', 'm'].includes(gender) || !SEASONS.includes(season)) return null;
  if (!TONES.includes(tone) || !tone.startsWith(`${season}-`)) return null;
  const p = fourInts(q.get('p'));
  const axes = fourInts(q.get('x'));
  if (!p || !axes) return null;
  if (borderline !== null && (!SEASONS.includes(borderline) || borderline === season)) return null;
```

```js
// 흐름: 스펙 6장. 프레임 → A4 보정 → 부위 측정 → 프레임 중앙값 → 특징 → 4축 → 판정
import { sampleRect, extractRegions } from './regions.js';
import { cardStats, checkCard, computeGains } from './calibrate.js';
import { measureRegion, combineFrames, hasGlare } from './measure.js';
import { buildFeatures, computeAxes } from './axes.js';
import { classify } from './classify.js';

const REGIONS = ['skin', 'iris', 'sclera', 'lip', 'brow', 'hair'];
const NO_GAIN = [1, 1, 1];

function mostCommon(codes) {
  const counts = new Map();
  for (const c of codes) counts.set(c, (counts.get(c) ?? 0) + 1);
  return [...counts.entries()].sort((a, b) => b[1] - a[1])[0][0];
}

export function analyze({ frames, settings, flags, config }) {
  if (!frames || frames.length === 0) return { ok: false, error: 'not_enough_frames' };
  const t = config.thresholds;
  const target = config.calibration.targets[settings.cardType ?? config.calibration.card];

  const perFrame = [];
  const cardErrors = [];
  for (const f of frames) {
    const stats = cardStats(sampleRect(f.image, settings.cardRect));
    const err = checkCard(stats, t);
    if (err) { cardErrors.push(err); continue; }
    const gains = computeGains(stats.mean, target);
    const px = extractRegions(f.image, f.landmarks, f.hairMask, t);
    if (hasGlare(px.iris, t.glareMinL, t.glareMaxRatio)) px.iris = [];
    const measured = { rawSkin: measureRegion(px.skin, NO_GAIN, t.trimPct, t.minRegionPixels) };
    for (const r of REGIONS) measured[r] = measureRegion(px[r], gains, t.trimPct, t.minRegionPixels);
    perFrame.push(measured);
  }
  if (perFrame.length * 2 < frames.length) return { ok: false, error: mostCommon(cardErrors) };

  const m = Object.fromEntries(REGIONS.map((r) => [r, combineFrames(perFrame.map((p) => p[r]))]));
  const rawSkin = combineFrames(perFrame.map((p) => p.rawSkin));
  if (!m.skin || !rawSkin) return { ok: false, error: 'no_skin' };
  if (rawSkin.L < t.minSkinL) return { ok: false, error: 'too_dark' };

  const warnings = [];
  if (m.sclera && m.sclera.C > t.scleraMaxChroma) warnings.push('sclera_chroma');
  if (cardErrors.length > 0) warnings.push(`card_frames_skipped:${cardErrors.length}`);

  const { features, excluded } = buildFeatures(m, flags, t);
  const axes = computeAxes(features, config);
  return { ok: true, result: { ...classify(axes, config), axes }, measurements: m, features, warnings, excluded };
}
```

```js
import { createServer } from 'node:http';
import { readFile } from 'node:fs/promises';
import { extname, join, resolve, sep } from 'node:path';
import { pathToFileURL } from 'node:url';

const TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.mjs': 'text/javascript; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.svg': 'image/svg+xml',
};

export function createStaticServer(root) {
  const base = resolve(root);
  return createServer(async (req, res) => {
    let file;
    try {
      const path = decodeURIComponent(new URL(req.url, 'http://localhost').pathname);
      file = resolve(join(base, path));
      if (file !== base && !file.startsWith(base + sep)) throw new Error('outside root');
      if (path.endsWith('/')) file = join(file, 'index.html');
      const body = await readFile(file);
      res.writeHead(200, { 'content-type': TYPES[extname(file)] ?? 'application/octet-stream', 'cache-control': 'no-store' });
      res.end(body);
    } catch {
      res.writeHead(404, { 'content-type': 'text/plain; charset=utf-8' });
      res.end('not found');
    }
  });
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
```

```js
// 웹캠 열기, 프레임 캡처, 화이트밸런스·노출 고정 시도 (wiki/measurement/webcam-limits.md)
export async function openCamera(video, deviceId) {
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: false,
    video: { deviceId: deviceId ? { exact: deviceId } : undefined, width: { ideal: 1280 }, height: { ideal: 720 } },
  });
  video.srcObject = stream;
  await video.play();
  return stream;
}

export function stopCamera(stream) {
  stream?.getTracks().forEach((t) => t.stop());
}

export async function listCameras() {
  const devices = await navigator.mediaDevices.enumerateDevices();
  return devices.filter((d) => d.kind === 'videoinput');
}

// 지원되면 현재 값으로 고정한다. 무엇이 지원되는지 운영자 화면에 보여준다.
export async function tryLockCamera(stream) {
  const track = stream.getVideoTracks()[0];
  const caps = track.getCapabilities ? track.getCapabilities() : {};
  const report = {
    whiteBalanceMode: caps.whiteBalanceMode ?? '지원 안 함',
    exposureMode: caps.exposureMode ?? '지원 안 함',
    colorTemperature: caps.colorTemperature ?? '지원 안 함',
    locked: [],
  };
  for (const key of ['whiteBalanceMode', 'exposureMode']) {
    if (Array.isArray(caps[key]) && caps[key].includes('manual')) {
      try {
        await track.applyConstraints({ advanced: [{ [key]: 'manual' }] });
        report.locked.push(key);
      } catch (e) {
        report[`${key}Error`] = String(e);
      }
    }
  }
  return report;
}

export function grabFrame(video, canvas) {
  canvas.width = video.videoWidth;
  canvas.height = video.videoHeight;
  const ctx = canvas.getContext('2d', { willReadFrequently: true });
  ctx.drawImage(video, 0, 0);
  return ctx.getImageData(0, 0, canvas.width, canvas.height);
}
```

```js
// MediaPipe: 얼굴 점 478개 + 머리카락 분리 (raw/web/mediapipe-segmenter.md)
const VISION = 'https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.1.0';
const FACE_MODEL = 'https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task';
const SEG_MODEL = 'https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_multiclass_256x256/float32/latest/selfie_multiclass_256x256.tflite';

async function withGpuFallback(create) {
  try {
    return await create('GPU');
  } catch {
    return create('CPU');
  }
}

export async function createDetectors() {
  const { FilesetResolver, FaceLandmarker, ImageSegmenter } = await import(`${VISION}/vision_bundle.mjs`);
  const fileset = await FilesetResolver.forVisionTasks(`${VISION}/wasm`);
  const landmarker = await withGpuFallback((delegate) => FaceLandmarker.createFromOptions(fileset, {
    baseOptions: { modelAssetPath: FACE_MODEL, delegate },
    runningMode: 'VIDEO',
    numFaces: 2,
  }));
  const segmenter = await withGpuFallback((delegate) => ImageSegmenter.createFromOptions(fileset, {
    baseOptions: { modelAssetPath: SEG_MODEL, delegate },
    runningMode: 'VIDEO',
    outputCategoryMask: true,
    outputConfidenceMasks: false,
  }));

  let ts = 0;
  const nextTs = () => (ts = Math.max(ts + 1, Math.round(performance.now())));

  return {
    detectFaces(source) {
      return landmarker.detectForVideo(source, nextTs()).faceLandmarks;
    },
    segmentHair(source) {
      const result = segmenter.segmentForVideo(source, nextTs());
      const mask = result.categoryMask;
      const out = mask ? { data: mask.getAsUint8Array().slice(), width: mask.width, height: mask.height } : null;
      result.close();
      return out;
    },
  };
}
```

```js
// 운영자 대화상자 (Ctrl+Shift+S): 웹캠 선택, 카드 종류, A4 영역 드래그, 진단 정보
import { listCameras } from './camera.js';
import { rectFromDrag, displayRectToRaw } from './settings.js';

const $ = (id) => document.getElementById(id);

export function setupOperator({ overlay, getSettings, setSettings, onCameraChange }) {
  const dialog = $('operator');
  let drag = null;

  document.addEventListener('keydown', (e) => {
    if (e.ctrlKey && e.shiftKey && e.code === 'KeyS') {
      e.preventDefault();
      if (dialog.open) dialog.close(); else open();
    }
  });
  $('op-close').addEventListener('click', () => dialog.close());

  async function open() {
    const cams = await listCameras();
    $('op-camera').innerHTML = cams
      .map((c, i) => `<option value="${c.deviceId}">${c.label || `카메라 ${i + 1}`}</option>`)
      .join('');
    $('op-camera').value = getSettings().deviceId ?? cams[0]?.deviceId ?? '';
    $('op-card').value = getSettings().cardType;
    dialog.showModal();
  }

  $('op-camera').addEventListener('change', (e) => {
    setSettings({ ...getSettings(), deviceId: e.target.value });
    onCameraChange(e.target.value);
  });
  $('op-card').addEventListener('change', (e) => setSettings({ ...getSettings(), cardType: e.target.value }));

  // 화면 좌표(0~1, 거울 모드) → 원본 프레임 좌표로 저장
  const pos = (e) => {
    const r = overlay.getBoundingClientRect();
    return { x: (e.clientX - r.left) / r.width, y: (e.clientY - r.top) / r.height };
  };
  $('op-card-rect').addEventListener('click', () => {
    dialog.close();
    overlay.dataset.mode = 'card';
  });
  overlay.addEventListener('pointerdown', (e) => {
    if (overlay.dataset.mode !== 'card') return;
    drag = { a: pos(e), b: pos(e) };
  });
  overlay.addEventListener('pointermove', (e) => { if (drag) drag.b = pos(e); });
  overlay.addEventListener('pointerup', () => {
    if (!drag) return;
    const rect = rectFromDrag(drag.a, drag.b);
    drag = null;
    delete overlay.dataset.mode;
    if (rect.w > 0.01 && rect.h > 0.01) setSettings({ ...getSettings(), cardRect: displayRectToRaw(rect) });
    open();
  });

  return {
    setCaps: (report) => { $('op-caps').textContent = JSON.stringify(report, null, 2); },
    setLast: (info) => { $('op-last').textContent = JSON.stringify(info, null, 2); },
    dragRect: () => (drag ? rectFromDrag(drag.a, drag.b) : null),
  };
}
```

```js
// 부스 화면 흐름: 대기 → 시작 → 촬영 → 분석 중 → 결과 (스펙 7.1)
import qrcode from 'https://cdn.jsdelivr.net/npm/qrcode-generator@2.0.4/dist/qrcode.mjs';
import { openCamera, stopCamera, tryLockCamera, grabFrame } from './camera.js';
import { createDetectors } from './face.js';
import { faceCheck } from './face-check.js';
import { analyze } from './pipeline.js';
import { encodeResult } from './result-code.js';
import { messageFor } from './messages.js';
import { renderResultHtml } from './result-view.js';
import { browserStorage, loadSettings, saveSettings, displayRectToRaw } from './settings.js';
import { setupOperator } from './operator.js';

const $ = (id) => document.getElementById(id);
const SCREENS = ['idle', 'start', 'capture', 'analyzing', 'result'];
const storage = browserStorage();
const video = $('video');
const overlay = $('overlay');

const state = {
  screen: 'idle', gender: null, settings: loadSettings(storage),
  config: null, palettes: null, detectors: null, stream: null,
  holdStart: null, lastFaceAt: Date.now(), busy: false, idleTimer: null,
};

const operator = setupOperator({
  overlay,
  getSettings: () => state.settings,
  setSettings: (s) => { state.settings = s; saveSettings(storage, s); },
  onCameraChange: (id) => startCamera(id),
});

function show(screen) {
  state.screen = screen;
  for (const s of SCREENS) $(`screen-${s}`).hidden = s !== screen;
  $('stage').hidden = !(screen === 'idle' || screen === 'capture');
  clearTimeout(state.idleTimer);
  if (screen === 'result') armIdleReset();
}

function showError(code) {
  $('error').textContent = messageFor(code);
  $('error').hidden = false;
  setTimeout(() => { $('error').hidden = true; }, 3000);
}

function armIdleReset() {
  clearTimeout(state.idleTimer);
  state.idleTimer = setTimeout(goHome, state.config.thresholds.idleResetSeconds * 1000);
}

function goHome() {
  state.gender = null;
  state.holdStart = null;
  document.querySelectorAll('.gender').forEach((b) => b.setAttribute('aria-pressed', 'false'));
  $('flag-dyed').checked = false;
  $('flag-lip').checked = false;
  $('btn-begin').disabled = true;
  $('result-body').innerHTML = '';
  $('qr').innerHTML = '';
  show('idle');
}

async function startCamera(deviceId) {
  stopCamera(state.stream);
  try {
    state.stream = await openCamera(video, deviceId);
  } catch {
    showError('camera_denied');
    return;
  }
  // 화면 밝기가 자리잡은 뒤(2초) 화이트밸런스·노출 고정을 시도한다
  setTimeout(async () => operator.setCaps(await tryLockCamera(state.stream)), 2000);
}

function drawOverlay(faces) {
  overlay.width = overlay.clientWidth;
  overlay.height = overlay.clientHeight;
  const ctx = overlay.getContext('2d');
  const W = overlay.width;
  const H = overlay.height;
  ctx.clearRect(0, 0, W, H);
  ctx.lineWidth = 3;
  // 얼굴 가이드 (화면 가운데 타원)
  ctx.strokeStyle = 'rgba(255,255,255,0.8)';
  ctx.beginPath();
  ctx.ellipse(W / 2, H / 2, W * 0.16, H * 0.38, 0, 0, Math.PI * 2);
  ctx.stroke();
  // A4 영역 (원본 좌표 → 거울 화면 좌표)
  const card = state.settings.cardRect ? displayRectToRaw(state.settings.cardRect) : null;
  const drag = operator.dragRect();
  for (const [r, color] of [[card, '#00c853'], [drag, '#ffab00']]) {
    if (!r) continue;
    ctx.strokeStyle = color;
    ctx.strokeRect(r.x * W, r.y * H, r.w * W, r.h * H);
  }
  // 얼굴 점 일부 (확인용)
  ctx.fillStyle = 'rgba(0,200,255,0.8)';
  for (const lm of faces) for (const i of [1, 234, 454, 205, 425, 9, 199, 468, 473]) {
    ctx.fillRect((1 - lm[i].x) * W - 2, lm[i].y * H - 2, 4, 4);
  }
}

const CAPTURE_TEXT = {
  no_face: '얼굴을 화면 가운데에 맞춰 주세요',
  multiple_faces: '한 명만 화면에 들어와 주세요',
  too_small: '조금 더 가까이 와 주세요',
  turned: '정면을 봐 주세요',
};

function tick() {
  requestAnimationFrame(tick);
  if (!state.detectors || state.busy || video.readyState < 2) return;
  if (state.screen !== 'idle' && state.screen !== 'capture') return;
  const faces = state.detectors.detectFaces(video);
  drawOverlay(faces);
  if (state.screen !== 'capture') return;

  const t = state.config.thresholds;
  const check = faceCheck(faces, video.videoWidth / video.videoHeight, t);
  const now = performance.now();
  if (faces.length > 0) state.lastFaceAt = Date.now();
  if (Date.now() - state.lastFaceAt > t.idleResetSeconds * 1000) { goHome(); return; }

  if (!check.ok) {
    state.holdStart = null;
    $('capture-msg').textContent = CAPTURE_TEXT[check.reason];
    $('countdown').textContent = '';
    return;
  }
  state.holdStart ??= now;
  const left = t.holdSeconds - (now - state.holdStart) / 1000;
  $('capture-msg').textContent = '좋아요! 움직이지 마세요';
  $('countdown').textContent = left > 0 ? String(Math.ceil(left)) : '';
  if (left <= 0) captureAndAnalyze();
}

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

async function captureAndAnalyze() {
  state.busy = true;
  const t = state.config.thresholds;
  let frames = [];
  for (let i = 0; i < t.framesPerCapture; i++) {
    const canvas = document.createElement('canvas');
    const image = grabFrame(video, canvas);
    const faces = state.detectors.detectFaces(canvas);
    if (faces.length === 1) frames.push({ image, landmarks: faces[0], hairMask: state.detectors.segmentHair(canvas) });
    await sleep(1000 / t.framesPerCapture);
  }
  show('analyzing');
  await sleep(50); // "분석 중" 화면이 그려질 시간을 준다

  const flags = { dyed: $('flag-dyed').checked, lipProduct: $('flag-lip').checked };
  const out = frames.length * 2 < t.framesPerCapture
    ? { ok: false, error: 'not_enough_frames' }
    : analyze({ frames, settings: state.settings, flags, config: state.config });
  frames = null; // 사진 참조를 버린다 (개인정보)

  operator.setLast(out.ok
    ? { result: out.result, measurements: out.measurements, features: out.features, warnings: out.warnings, excluded: out.excluded }
    : out);
  state.busy = false;
  state.holdStart = null;

  if (!out.ok) {
    showError(out.error);
    show('capture');
    return;
  }
  showResult(out.result);
}

function showResult(result) {
  $('result-body').innerHTML = renderResultHtml(result, state.palettes);
  const url = new URL(`result.html?${encodeResult({ ...result, gender: state.gender })}`, location.href).href;
  const qr = qrcode(0, 'M');
  qr.addData(url);
  qr.make();
  $('qr').innerHTML = qr.createSvgTag(6, 8);
  show('result');
}

// 버튼 연결
$('btn-start').addEventListener('click', () => show('start'));
document.querySelectorAll('.gender').forEach((b) => b.addEventListener('click', () => {
  state.gender = b.dataset.gender;
  document.querySelectorAll('.gender').forEach((x) => x.setAttribute('aria-pressed', String(x === b)));
  $('btn-begin').disabled = false;
}));
$('btn-begin').addEventListener('click', () => {
  state.lastFaceAt = Date.now();
  show('capture');
});
$('btn-home').addEventListener('click', goHome);
for (const ev of ['pointermove', 'pointerdown', 'keydown']) {
  document.addEventListener(ev, () => { if (state.screen === 'result') armIdleReset(); });
}

async function init() {
  show('idle');
  [state.config, state.palettes] = await Promise.all([
    fetch('data/seasons.json').then((r) => r.json()),
    fetch('data/palettes.json').then((r) => r.json()),
  ]);
  await startCamera(state.settings.deviceId);
  try {
    state.detectors = await createDetectors();
  } catch (e) {
    console.error(e);
    showError('model_failed');
    return;
  }
  requestAnimationFrame(tick);
}

init();
```

Run: `npm run serve` 후 Chrome에서 `http://localhost:8080/app/` 열기. 아래를 하나씩 확인하고 결과를 기록한다.

1. 카메라 권한 허용 → 거울 모드 미리보기가 보이고, 얼굴에 파란 점이 찍힌다.
2. 카메라 권한 거부(주소창 자물쇠 → 카메라 차단 → 새로고침) → "카메라를 사용할 수 없어요" 문구가 보인다. 확인 후 다시 허용.
3. `Ctrl+Shift+S` → 운영자 대화상자. "카메라 제어 지원"에 `whiteBalanceMode` 값과 `locked` 목록이 보인다 → **이 값을 위키 `measurement/webcam-limits.md`에 기록**(Windows Chrome 지원 여부, 스펙 열린 항목).
4. "A4 영역 지정" → 화면의 A4 위를 드래그 → 초록 사각형이 A4 위에 그려진다. 새로고침해도 유지된다.
5. 시작 → 성별 → 진단 시작 → 얼굴을 맞추면 3초 카운트다운 → 분석 중 → 결과(계절, %, 12톤, 4축, 색 칩, QR).

- [ ] **Step 2: `app/src/result-page.js`**

```js
// QR로 여는 결과 페이지: URL의 숫자만 읽는다 (스펙 7.2, 7.4)
import { decodeResult } from './result-code.js';
import { renderResultHtml } from './result-view.js';

const body = document.getElementById('result-body');
const result = decodeResult(location.search);

if (!result) {
  body.innerHTML = '<p class="error">결과 링크가 올바르지 않아요. 부스에서 QR을 다시 찍어 주세요.</p>';
} else {
  fetch('data/palettes.json')
    .then((r) => r.json())
    .then((palettes) => { body.innerHTML = renderResultHtml(result, palettes); })
    .catch(() => { body.innerHTML = '<p class="error">결과를 불러오지 못했어요. 잠시 뒤 다시 열어 주세요.</p>'; });
}
```
