# 퍼지 기반의 퍼스널 컬러 진단 시스템 및 그 방법 (KR20100074412A)

- URL: https://patents.google.com/patent/KR20100074412A/ko
- 확인일: 2026-10-12
- 종류: 특허
- 열람 수준: 원문(요약)

## 핵심 내용
- 입력: 피부색, 머리카락색, 눈동자색 (색 선택, 코드 입력, 카메라 이미지 여러 번 측정 평균)
- 색 표현: RGB, HSB, Lab, CMYK 지원
- 계절 모델을 퍼지 집합으로 저장
- 소속도 = (선택 계절과의 거리의 역수) / (모든 계절에 대한 거리 역수의 합)
- 최소 유클리드 거리의 계절 모델을 선택
- 부위 가중치: 피부 > 머리카락 > 눈동자
- 구체적인 수치 임계값은 공개되지 않음
