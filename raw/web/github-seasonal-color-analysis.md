## 핵심 내용
- MediaPipe Face Mesh로 얼굴 점 검출
- 측정 부위: 피부 여러 영역(HSV 필터 + 백분위 이상치 처리), 홍채, 눈썹, 입술 (표본이 부족하면 대체값 사용)
- 특징: HSV, CIE Lab, 색상각, b/a 비, ITA, 언더톤(쿨/웜), 피부 깊이, 명도·채도 추정, 피부·눈썹·눈 대비
- 분류: 12톤 가중 규칙 점수 (학습 모델 아님). 점수는 확률이 아니라 근거 점수
- 정확도 주장 없음. 한계: 조명, 화이트밸런스, 그림자, 화장, 가림, 고개 각도. 라벨 데이터로 검증되지 않음
- 라이선스 미확인 → 코드는 쓰지 않고 방식만 참고
