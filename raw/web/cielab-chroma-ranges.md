# CIELAB 채도 구간과 피부 LCh 해석

- URL: https://onlinelibrary.wiley.com/doi/full/10.1002/col.70012
- 확인일: 2026-10-12
- 종류: 웹
- 열람 수준: 검색 요약

## 핵심 내용
- CIELAB 채도 C* < 18: 탁함, 18~30: 중간, > 30: 선명(rich)
- LCh에서 명도(L)는 깊이, 색상각(h)과 채도(C)는 언더톤을 나타냄. 온도는 색상각, 선명도는 채도
- 자동 진단 특허 사례: 채도는 얼굴 특징 색의 채도 합으로, 대비는 밝기 변동으로 계산
