# ITA(Individual Typology Angle) 피부 밝기 분류

- URL: https://arxiv.org/pdf/2104.02926
- 확인일: 2026-10-12
- 종류: 웹
- 열람 수준: 검색 요약

## 핵심 내용
- ITA = arctan((L* − 50) / b*) × 180/π
- 분류 구간 (Chardon 1991, 일반적으로 인용되는 구간이며 원문은 미열람): 매우 밝음 > 55°, 밝음 41~55°, 중간 28~41°, 황갈 10~28°, 갈색 −30~10°, 어두움 < −30°
- 사용 사례: Dlib 얼굴 점으로 이마·양 볼을 찾고, 영역별 픽셀 ITA를 평활화한 뒤 최빈값을 평균해 얼굴 하나의 피부톤 추정
