# Practical Color Coordinate System (PCCS)

- URL: https://en.wikipedia.org/wiki/Practical_Color_Coordinate_System
- 확인일: 2026-10-12
- 종류: 웹
- 열람 수준: 검색 요약

## 핵심 내용
- 일본색채연구소가 만든 색 체계. 색상·명도·채도를 '톤'으로 묶어 다룸. 아시아 퍼스널컬러 진단의 기반
- 12톤 — 고채도: vivid(v), bright(b), strong(s), deep(dp) / 중채도: light(lt), soft(sf), dull(d), dark(dk) / 저채도: pale(p), light grayish(ltg), grayish(g), dark grayish(dkg)
- 흰색만 섞은 톤: p, lt, b. 검정만 섞은 톤: dp, dk, dkg. 흰색과 검정을 모두 섞은 톤: ltg, sf, s, d, g
- vivid는 가장 높은 채도, 탁함 없음. soft는 중간 명도·채도로 부드럽고 따뜻한 인상
