# 퍼스널컬러(퍼컬) 뜻과 원리 · 네 가지 기준, 20톤, 결과 쓰는 법 (톤모아)

## 핵심 내용
- 4기준: 색온도(골드 vs 실버를 대어 비교), 명도, 채도(선명 vs 탁함), 대비(피부와 머리카락·눈의 밝기 차이)
- 20톤 체계: 봄 4(라이트, 비비드, 브라이트, 소프트), 여름 6(뮤트 라이트, 뮤트, 뮤트 다크, 라이트, 브라이트, 트루), 가을 6(뮤트 라이트, 뮤트 소프트, 뮤트, 다크, 스트롱, 트루), 겨울 4(소프트, 비비드, 다크, 트루)
- 드레이핑: 진단자가 실제 조명 아래에서 여러 색 천을 얼굴 옆에 대고 비교. 진단자의 교육 체계에 따라 결과가 다를 수 있음
- 오해: 밝은 피부가 곧 쿨은 아님 (명도와 온도는 별개 축). 노란 기만으로 확정할 수 없음. 자주 입는 색은 익숙해서 어울려 보일 수 있음. 얼굴에서 먼 색은 비교적 자유로움
- 한계: 사진 분석은 조명·화이트밸런스·화장·필터의 영향을 받음. AI 사진 분석은 실물 드레이핑으로 검증되지 않음
- 적용 우선순위(얼굴과 가까운 순): 립·블러셔 → 파운데이션 → 헤어 컬러 → 상의 → 금속 액세서리(골드, 로즈골드, 실버)
- 예: 봄 라이트와 여름 라이트 모두 파스텔이 어울리지만, 립은 봄 라이트가 노란 기 있는 코랄·피치, 여름 라이트가 푸른 기 있는 쿨 로즈
