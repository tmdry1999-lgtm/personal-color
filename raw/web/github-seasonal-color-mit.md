## 핵심 내용
- 라이선스: MIT
- HSV 색 범위로 피부 분리 (학습 모델 없음, PIL + numpy)
- 피부 색상각의 원형 평균으로 언더톤 판정 (웜 = 주황 쪽, 쿨 = 분홍 쪽)
- 밝기로 깊이(light/medium/deep) 판정
- 언더톤 × 깊이 → 12톤, 8색 팔레트·베스트·워스트 출력
